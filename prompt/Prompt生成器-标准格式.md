# Prompt 生成器 - 标准格式

> [!abstract] 核心目标
> 这是一个 **Meta Prompt**，用来指导 AI 按照标准格式生成你的 Prompt 库中的提示词。使用这个 prompt，AI 会自动输出符合你的格式规范的内容。

```
我需要你帮我生成一个专业的 Prompt，并按照我的标准格式输出。

## 标准格式要求：

你的输出必须严格遵循以下 Markdown 格式：

---
title: [Prompt 标题 - 简洁、明确]
created: [今天日期，格式：YYYY-MM-DD]
updated: [今天日期，格式：YYYY-MM-DD]
tags:
  - prompt
  - [标签1 - 必填：主题分类]
  - [标签2 - 可选]
  - [标签3 - 可选]
category: [分类 - 如：AI、前端、产品、运营等]
status: active
---

## 重点要求：

1. **YAML 前置属性** - 必须在文件最开头，完整填写
2. **核心提示词** - 放在标准的三反引号代码块内，这是最关键的部分
3. **📋 结构** - 保持这个符号和格式不变
4. **表格格式** - 使用 Markdown 表格展示特点，最少 3 行
5. **4 步骤格式** - 使用方式固定为 4 个步骤
6. **Wiki 链接** - 相关笔记使用 [[]] 格式

## 📌 提示词说明

### 使用场景
这个 Meta Prompt 用于**指导 AI 生成标准格式的 Prompt**，帮助你：
- ✅ 自动获得符合你格式的高质量 Prompt
- ✅ 保持 Prompt 库的一致性和专业性
- ✅ 节省手动调整格式的时间
- ✅ 建立可复用的 Prompt 生成流程

### 关键特点
| 维度 | 说明 |
|------|------|
| **自动化** | AI 自动按格式生成，无需手动调整 |
| **一致性** | 所有 Prompt 遵循统一的结构和样式 |
| **完整性** | 包含元数据、说明、使用指南全套 |
| **可维护** | 格式规范，易于查阅和更新 |

## 🎯 使用方式
