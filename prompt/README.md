## 📖 模板和指南

### 创建新 Prompt 的步骤

1. **复制模板**
   - 打开 [[prompt/_template.md|Prompt 模板]]
   - 复制内容到新文件

2. **填写必要字段**
   ```yaml
   title: [Prompt 标题]
   tags: [标签列表]
   category: [分类]
   status: active/archived/draft
   ```

3. **核心提示词**
   - 将完整的 prompt 放在 ``` 代码块里
   - 确保语言清晰、结构完整

4. **补充说明**
   - 使用场景（这个 prompt 什么时候用）
   - 关键特点（表格形式对比）
   - 使用方式（4 步骤）

5. **保存和分类**
   - 使用标签系统（#prompt [[AI]] [[前端）]]
   - 更新本索引文件

## 🎓 Prompt 设计原则

| 原则 | 说明 |
|------|------|
| **清晰** | 目标明确，不模糊 |
| **结构化** | 分步骤、分模块 |
| **可执行** | 包含具体例子和格式要求 |
| **可维护** | 易于查找、更新、版本管理 |
| **有上下文** | 记录使用场景和效果 |
