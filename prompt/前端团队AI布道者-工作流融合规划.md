# 前端团队AI布道者 - 工作流融合规划

> [!abstract] 核心目标
> 为前端团队设计一份**AI深度融合工作流的全景规划**，帮助团队从"探索和浅层应用"升级到"AI在各个工作流环节深度介入并产生实质性作用"的状态。

## 📋 核心提示词

```
你是一位资深的前端技术专家和AI应用战略师，擅长将AI技术深度融合到软件开发流程中。

## 你的任务：
为一个前端团队设计一份**"AI深度融合工作流全景规划"**，帮助团队从当前的"探索和浅层应用"阶段，升级到"AI在各个工作流环节深度介入并产生实质性作用"的状态。

## 规划的核心要求：

1. **完整的工作流覆盖**
   - 梳理前端工作的完整生命周期（包括但不限于：需求阶段、开发阶段、审核阶段、上线阶段）
   - 对于每个阶段，你需要补充识别出其他可能被忽视的关键环节（如架构设计、文档维护、性能监控、技术债管理等）

2. **深度融合的定义**
   - "深度融合"意味着：AI不仅是辅助工具，而是**介入流程、改变工作方式、产生实质性业务价值**
   - 每个AI应用点都应该清晰回答：**做什么、怎么做、产生什么实质性作用**

3. **架构的完整性**
   - 提供一个**清晰的全景视图**：展示AI在各阶段的角色和相互关联
   - 识别高优先级的AI融合点（立竿见影的、容易实施的）vs 长期建设项（复杂但高价值的）
   - 考虑工具链、流程改造、团队能力建设等维度

4. **可执行性指导**
   - 对于每个关键的AI融合点，提出**具体的AI工具或方案**（如代码生成、智能审查、自动化测试等）
   - 说明**实施的前置条件**和**预期的实质性作用**（效率提升、质量改进、创意增强等）

5. **组织和呈现**
   - 用清晰的结构组织规划（可以是思维导图式、阶段式、或优先级式）
   - 每个AI融合点都用简洁的方式标注其**优先级、难度、预期收益**

## 输出格式：
- 提供一份**结构化的规划文档**（用markdown或outline形式均可）
- 包含一个**全景总结**（高层视图，1-2张逻辑图或总结表格最佳）
- 为前3-5个最有价值的AI融合点提供**详细的落地建议**

## 注意事项：
- 考虑团队目前处于"探索和浅层应用"阶段，要有循序渐进的思路
- 避免空洞的理论，每个建议都要有具体的应用场景和工具示例
- 强调"实质性作用"而非"看起来很酷"的功能

开始为我梳理这份规划吧！
```

## 📌 提示词说明

### 使用场景
这个提示词用于**内部思路梳理**，帮助你和团队明确：
- ✅ AI在前端工作流各阶段的具体应用点
- ✅ 如何从浅层应用升级到深度融合
- ✅ 优先级和实施路线图

### 关键特点
| 维度 | 说明 |
|------|------|
| **深度** | 从需求→开发→审核→上线的全生命周期 |
| **实质性** | 关注实际业务价值，而非噱头功能 |
| **可执行** | 包含具体工具方案和前置条件 |
| **渐进式** | 考虑团队现状，循序渐进的路线图 |

## 🎯 使用方式

1. **复制核心提示词**（上方代码块）
2. **粘贴给你的AI助手**（Claude、ChatGPT 等）
3. **获得规划文档**（结构化的AI融合方案）
4. **迭代完善**（根据团队实际调整）
