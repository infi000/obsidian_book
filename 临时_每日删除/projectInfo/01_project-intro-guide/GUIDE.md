# 维度一：项目介绍 (Project Introduction)

这是知识库的**第一维度**，帮助新成员快速了解项目的基本信息、架构和技术选择。

## 📋 这个维度包含的内容

| 文件 | 用途 | 内容 |
|-----|------|------|
| **overview.md** | 项目概述 | 项目做什么、为什么做、核心特性、主要用户 |
| **architecture.md** | 架构设计 | 系统架构、技术选择、关键模块、数据流 |
| **tech-stack.md** | 技术栈 | 前端、后端、DevOps 技术列表 |

## 🎯 这个维度的作用

- 新成员快速了解项目
- 理解系统架构和设计选择
- 查阅技术栈信息
- 了解项目的商业价值

## 📝 如何编写

### overview.md - 项目概述

这是项目的简介文档。格式和内容遵守:`./templates/overview.md`

### architecture.md - 架构设计

这是系统设计文档。格式和内容遵守:`./templates/architecture.md`


### tech-stack.md - 技术栈

这是技术栈清单。格式和内容遵守:`./templates/tech-stack.md`


## ✅ 检查清单

创建这个维度的文档时，确保：

- [ ] **overview.md** 包含：是什么、为什么、特性、用户、链接
- [ ] **architecture.md** 包含：架构图、技术选择表、关键模块、数据流
- [ ] **tech-stack.md** 包含：前端、后端、DevOps、工具的完整列表
- [ ] 所有链接都是可访问的（指向实际存在的文档）
- [ ] 内容清晰简洁，没有冗余信息
- [ ] 如果有变更，及时更新这些文件
