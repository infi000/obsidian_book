# 维度二：开发规范 (Development Standards)

这是知识库的**第二维度**，是最重要的部分。定义项目的代码规范、命名约定、文件结构和 Git 工作流。

## 📋 这个维度包含的内容

| 文件 | 用途 | 内容 |
|-----|------|------|
| **overview.md** | 规范导航 | 所有规范的索引和快速导航 |
| **code-standards.md** | 代码规范 | JavaScript/TypeScript、React、注释等规范 |
| **naming-conventions.md** | 命名规范 | 文件、变量、函数、CSS 的命名规则 |
| **file-structure.md** | 文件结构 | 项目文件夹组织方式 |
| **git-workflow.md** | Git 规范 | 分支命名、提交信息、PR 规范 |

## 🎯 这个维度的作用

- **Code Review 时的参考标准** - 审核代码是否符合规范
- **新成员的编码指南** - 快速学习项目的编码风格
- **降低技术债** - 统一风格，减少重构
- **提高代码质量** - 规范化促进质量提升

## ✅ 检查清单

创建这个维度的文档时，确保：

- [ ] **overview.md** 包含快速导航和场景查询
- [ ] **code-standards.md** 包含 JS/TS、React、注释、导入等规范
- [ ] **naming-conventions.md** 包含文件、变量、函数命名规则和示例
