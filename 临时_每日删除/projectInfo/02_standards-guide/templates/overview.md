# 开发规范总览

这是项目的规范中心，所有开发者都应该遵守这些规范。

## 快速导航

| 规范 | 说明 | 何时使用 |
|-----|------|--------|
| [[code-standards|代码规范]] | 编码风格、最佳实践 | 编写代码时 |
| [[naming-conventions|命名规范]] | 文件、变量、函数命名 | 新建文件或变量时 |
| [[file-structure|文件结构]] | 项目文件组织方式 | 新建文件夹或模块时 |
| [[git-workflow|Git 规范]] | 提交、分支、PR 规范 | 提交代码时 |

## 按场景查询

### 场景 1: 我要新建一个组件
1. 先看 [[file-structure|文件结构]] - 选择合适的文件夹
2. 再看 [[naming-conventions|命名规范]] - 命名组件
3. 最后看 [[code-standards|代码规范]] - React 规范部分

### 场景 2: 我要提交代码
1. 先看 [[code-standards|代码规范]] - 确保代码格式正确
2. 再看 [[git-workflow|Git 规范]] - 编写提交信息
3. 最后创建 PR

### 场景 3: Code Review
1. 看所有的规范文件，逐一检查
