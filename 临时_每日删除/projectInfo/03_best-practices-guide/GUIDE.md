# 维度三：最佳实践 (Best Practices)

这是知识库的**第三维度**，提供项目中的推荐做法、常见模式和优化建议。

## 📋 这个维度包含的内容

| 文件 | 用途 | 内容 |
|-----|------|------|
| **overview.md** | 最佳实践导航 | 所有最佳实践的索引 |
| **common-patterns.md** | 常见模式 | Redux 数据流、异步操作、错误处理等 |
| **performance-tips.md** | 性能优化 | React 优化、网络优化、打包优化 |
| **security-guidelines.md** | 安全指南 | XSS、CSRF、敏感信息等防护 |

## 🎯 这个维度的作用

- **code review** - 检查代码是否符合最佳实践的参考
- **指导开发** - 遵循最佳实践写出更好的代码
- **性能优化** - 了解常见的性能瓶颈和优化方案
- **安全防护** - Code Review 时检查安全问题
- **技术积累** - 记录项目中有效的设计模式

## ✅ 检查清单

创建这个维度的文档时，确保：

- [ ] **overview.md** 包含导航和核心原则
- [ ] **common-patterns.md** 包含项目实际使用的模式（Redux、异步等）
- [ ] **performance-tips.md** 包含具体的优化示例和何时使用
- [ ] **security-guidelines.md** 包含常见的安全问题和防护方法
- [ ] 所有代码示例都有 ✅ 和 ❌ 对比
- [ ] 内容基于项目的实际经验，不是通用指南
