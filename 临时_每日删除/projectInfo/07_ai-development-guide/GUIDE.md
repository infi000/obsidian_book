# 维度七：AI 开发指南 (AI Development Guide)

这是知识库的**第七维度**，帮助团队利用 AI 工具提高开发效率。包括 AI 工具选择、项目规范配置、技能管理、工作流规范和公共技能库。

## 📋 这个维度包含的内容

| 文件 | 用途 | 内容 |
|-----|------|------|
| **AI 工具选择** | 工具对比与配置 | Claude Code、TDDC-CLI 等工具的选择和配置 |
| **文件组织架构** | 目录结构规范 | `.sfcode/` 目录的标准结构和各部分功能 |
| **项目概览** | SFCODE.md 指南 | 项目规范文档的编写说明（8 个核心部分） |
| **技能规范** | 技能管理指南 | 创建、注册、管理和使用 Skills 的规范 |
| **流程规范** | 开发工作流 | 从需求分析到上线的 6 阶段标准流程 |
| **公共技能库** | 技能共享 | 使用和贡献公共技能库的指南 |

## 🎯 这个维度的作用

- **加速开发** - 利用 AI 工具和技能快速实现功能
- **规范流程** - 建立统一的 AI 工作流和规范
- **知识共享** - 创建和贡献可复用的技能
- **降低成本** - 减少重复工作，提高团队效率
- **提升质量** - 通过 AI 辅助代码审查和测试

## 📝 如何编写这个维度

### 🆕 项目初始化 AI 环境

按照以下顺序：

1. **查看 [[references/ai-tools-selection|AI 工具选择]]**
   - 了解支持的 AI 工具
   - 选择合适的工具
   - 配置 CLAUDE.md / AGENT.md

2. **学习 [[references/file-organization|文件组织架构]]**
   - 了解 `.sfcode/` 目录结构
   - 创建规范的目录
   - 理解各部分功能

3. **编写 [[references/project-overview|项目概览 (SFCODE.md)]]**
   - 按照 8 部分框架编写
   - 让 AI 理解项目
   - 定义项目约束

### 🛠️ 创建和使用技能

按照以下顺序：

1. **学习 [[references/skill-standards|技能规范]]**
   - 理解技能的生命周期
   - 创建新技能的步骤
   - 注册技能到 AGENTS.md

2. **查看 [[references/public-skills-library|公共技能库]]**
   - 浏览现有的公共技能
   - 复用相关技能
   - 了解贡献流程

3. **遵循 [[references/workflow-standards|流程规范]]**
   - 了解 6 阶段开发流程
   - 在工作流中使用技能
   - 自动化各个开发环节

## ✅ 检查清单

### 新项目初始化

- [ ] 选择 AI 工具（Claude Code 或 TDDC-CLI）
- [ ] 在项目根目录创建 `CLAUDE.md` 和 `AGENT.md`
- [ ] 创建 `.sfcode/` 目录结构
- [ ] 编写详细的 `SFCODE.md` 项目规范
- [ ] 初始化 `AGENTS.md` 技能注册表
- [ ] 根据项目需求创建或导入技能

### 使用 AI 进行开发

- [ ] 理解 SFCODE.md 中的项目信息
- [ ] 熟悉可用的技能（从 AGENTS.md 查看）
- [ ] 按照流程规范执行开发
- [ ] 遵循规范的 commit 和提交流程
- [ ] 根据项目需求优化或创建新技能

### 贡献公共技能

- [ ] 技能已在多个项目中验证
- [ ] 编写完整的文档（SKILL.md + README.md）
- [ ] 代码规范且可复用
- [ ] 经过团队审核
- [ ] 提交到公共技能库
