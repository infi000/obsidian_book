## 贡献方式

### 添加新的 FAQ

如果你解决了一个常见问题：

1. 进入 [[faq|常见问题]] 文件
2. 添加新的 Q&A
3. 提交 PR

### 添加新术语

如果你发现了新的术语需要定义：

1. 进入 [[glossary|术语表]] 文件
2. 按字母顺序添加术语
3. 提交 PR

### 添加有用链接

如果你找到了有用的资源：

1. 进入 [[useful-links|有用链接]] 文件
2. 添加链接和说明
3. 提交 PR
