# 维度六：参考资料 (Reference)

这是知识库的**第六维度**，包含常见问题、术语表和有用链接，是团队知识积累的地方。

## 📋 这个维度包含的内容

| 文件 | 用途 | 内容 |
|-----|------|------|
| **overview.md** | 参考资料导航 | 所有参考资料的索引 |
| **faq.md** | 常见问题 | 项目相关的常见问题和答案 |
| **glossary.md** | 术语表 | 项目中使用的专业术语和定义 |
| **useful-links.md** | 有用链接 | 相关文档、资源和工具的链接 |

## 🎯 这个维度的作用

- **快速查询** - 遇到问题直接查 FAQ
- **术语统一** - 团队使用相同的术语
- **资源集合** - 整理项目相关的文档和资源
- **知识沉淀** - 记录团队遇到的问题和解决方案

## 📝 如何编写

### overview.md - 参考资料导航
参考资料导航，格式和内容遵守::`./templates/overview.md`


### faq.md - 常见问题
常见问题，格式和内容遵守::`./templates/faq.md`


### glossary.md - 术语表
常见问题，格式和内容遵守::`./templates/glossary.md`


### useful-links.md - 有用链接
有用链接，格式和内容遵守::`./templates/ useful-links.md`


## ✅ 检查清单

创建这个维度的文档时，确保：

- [ ] **overview.md** 包含导航和按场景查询指南
- [ ] **faq.md** 包含 10+ 常见问题和详细答案
- [ ] **glossary.md** 包含 20+ 专业术语和定义
- [ ] **useful-links.md** 包含 30+ 有用的链接和资源
- [ ] 所有链接都是有效的（不要有死链）
- [ ] FAQ 的答案都引用了相关文档
- [ ] 术语表按字母顺序组织
- [ ] 鼓励团队贡献和更新
