## 🎁 核心代码快速查看

### 三个核心文件

#### 文件 1：VCS 适配器（144 行）
```typescript
// adapters/vcs-adapter.ts
核心功能：
  • VCSAdapter 抽象类（定义通用接口）
  • GitLabAdapter（实现 GitLab API 调用）
  • BitbucketAdapter（实现 Bitbucket API 调用）
  • VCSFactory（工厂类，自动选择正确的实现）

设计模式：Adapter Pattern + Factory Pattern
```

#### 文件 2：核心 Agent（215 行）
```typescript
// agents/release-report-agent.ts
核心功能：
  • ReleaseReportAgent 类（主要逻辑）
  • generateFromSingleVCS()（单仓库报告生成）
  • generateCombinedReport()（多仓库报告生成）
  • generateMarkdown()（报告转换为 Markdown）
  • saveReport()（报告保存）

工作流：获取 PR → 统计改动 → 聚合数据 → 生成报告
```

#### 文件 3：CLI 入口（50 行）
```typescript
// cli.ts
核心功能：
  • 环境变量加载和验证
  • 命令行参数处理
  • Agent 初始化和运行
  • 错误处理和输出

特点：简洁清晰，易于扩展
```

**总计代码量**：~410 行（包括注释和空行）

## 💬 常见疑虑（解答）

### Q: 是不是要学 TypeScript？
**A**: 不用！你可以直接使用提供的代码。想修改的话，基础 TypeScript 知识就够了（1-2 天学完）。

### Q: 代码会不会过时？
**A**: 不会。我使用的是稳定的 API（GitLab v4、Bitbucket 2.0），这些 API 多年都不变。

### Q: 如果 Token 过期怎么办？
**A**: 验证脚本会立即告诉你。只需重新生成 Token，更新 .env，继续用。

### Q: 能在 Windows 上运行吗？
**A**: 完全可以！提供了 setup.bat 脚本，一键安装。

### Q: 需要 root 权限吗？
**A**: 不需要。只需要普通用户权限。

### Q: 能在 Docker 中运行吗？
**A**: 可以，但需要自己写 Dockerfile。基础项目不提供。

### Q: 报告大小会很大吗？
**A**: 不会。通常一份报告 5-20KB，一年 52 个版本也才 260-1040KB。
