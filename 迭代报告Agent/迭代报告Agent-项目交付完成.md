## 💡 关键提示

### 最重要的事（必读）

```
1️⃣  先读《交付总结》（5 分钟）
    不要跳过，它会让一切变得清晰

2️⃣  准备好 GitLab/Bitbucket 信息
    地址、Project ID、Token
    这是部署的前提条件

3️⃣  按照《项目初始化包》逐步做
    不要跳步，不要自作聪明
    每一步都有原因

4️⃣  一定要运行 validate-config.ts
    这会诊断 90% 的问题
```

### 常见陷阱（避免）

```
❌ 不要跳过验证步骤
   → 必须运行 validate-config.ts

❌ 不要把 .env 提交到 git
   → 会泄露你的 Token

❌ 不要复制过期的 Token
   → Token 过期是最常见的问题

❌ 不要修改核心代码
   → 除非你完全理解逻辑

❌ 不要同时实现多个 Phase
   → 一个一个来，避免复杂度爆炸
```
