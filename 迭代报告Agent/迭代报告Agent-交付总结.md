## 📞 常见问题速答

### Q1: 需要多长时间部署？

**A**:
- 从零开始：30-45 分钟
- 已有 Node.js 和 Token：15-20 分钟
- 使用自动脚本：5-10 分钟

### Q2: 会影响现有的工作流吗？

**A**: 完全不会。Agent 只是读取 VCS 的信息，不修改任何东西。

### Q3: Token 泄露了怎么办？

**A**:
1. 立即在 VCS 系统中删除该 Token
2. 生成新的 Token
3. 更新 .env 文件
4. 如果提交到 git 了，立即从 git 历史中删除

### Q4: 能支持我自己的 VCS 吗？

**A**: 可以！代码使用 Adapter Pattern，很容易扩展。参考 GitLabAdapter 创建新的适配器。

### Q5: 报告格式能改吗？

**A**: 完全可以。修改 `generateMarkdown()` 方法即可自定义报告格式。

### Q6: 能自动上传到文档系统吗？

**A**: MVP 不支持，但已规划（Phase 3）。参考《自建系统定制方案.md》可自己实现。
