# 记忆工具 (`save_memory`)

这份文档描述了 Gemini CLI 中的 `save_memory` 工具。

---

## **描述**

使用 `save_memory` 在您的 Gemini CLI 会话之间保存和回忆信息。通过 `save_memory`，您可以指示 CLI 在会话之间记住关键详情，提供个性化和有针对性的协助。

### **参数**

`save_memory` 接收一个参数：

- **`fact`** (字符串，必需) - 要记住的特定事实或信息。这应该是一个清晰的、独立的自然语言陈述。

---

## **如何在 Gemini CLI 中使用 `save_memory`**

该工具将提供的 `fact` 附加到位于用户主目录中的特殊 `GEMINI.md` 文件（`~/.gemini/GEMINI.md`）。此文件可以配置为其他名称。

添加后，事实存储在 `## Gemini Added Memories` 部分下。此文件在后续会话中作为上下文加载，允许 CLI 回忆保存的信息。

**使用方法：**

```
save_memory(fact="您的事实在这里。")
```

### **`save_memory` 示例**

#### **记住用户偏好**

```
save_memory(fact="我首选的编程语言是 Python。")
```

#### **存储项目特定的详情**

```
save_memory(fact="我目前正在从事的项目叫做 'gemini-cli'。")
```

#### **保存个人工作风格**

```
save_memory(fact="我倾向于使用函数式编程范式而不是面向对象编程。")
```

#### **记录技术偏好**

```
save_memory(fact="我在处理数据分析任务时喜欢使用 Pandas 库。")
```

---

## **重要说明**

| 方面 | 说明 |
|-----|------|
| **一般用途** | 此工具应用于简洁、重要的事实。不适合存储大量数据或对话历史 |
| **内存文件** | 内存文件是纯文本 Markdown 文件，如需要可以手动查看和编辑 |
| **会话跨越** | 保存的事实在所有后续 Gemini CLI 会话中可用 |
| **文件位置** | 默认位置：`~/.gemini/GEMINI.md`（可配置） |
| **自动加载** | 内存文件在每个会话启动时自动加载作为上下文 |

## **工作流程**

### **1. 保存信息**

当您使用 `save_memory` 时：

```
用户输入：save_memory(fact="我是一位前端开发者，使用 React 和 TypeScript。")
       ↓
   工具执行
       ↓
信息被附加到 ~/.gemini/GEMINI.md
```

### **2. 后续会话中使用**

```
新会话启动
       ↓
CLI 加载 ~/.gemini/GEMINI.md
       ↓
保存的事实作为上下文可用
       ↓
模型可引用此信息以提供个性化响应
```

## **最佳实践**

### **✅ 应该保存**

- 📌 持久的个人偏好（编程语言、工具选择）
- 📌 长期项目信息（项目名称、目标）
- 📌 工作风格或方法论偏好
- 📌 重复使用的技术背景
- 📌 重要的工作约束或限制

### **❌ 不应该保存**

- 🚫 会话特定的对话内容
- 🚫 临时任务或一次性信息
- 🚫 大量数据或文件内容
- 🚫 敏感的个人信息
- 🚫 频繁变化的信息

## **管理您的记忆**

### **查看保存的记忆**

打开和查看您的记忆文件：

```bash
cat ~/.gemini/GEMINI.md
```

### **手动编辑记忆**

您可以直接编辑文件以添加、修改或删除信息：

```bash
nano ~/.gemini/GEMINI.md
# 或
vim ~/.gemini/GEMINI.md
```

### **清除记忆**

如果需要清除所有记忆，可以删除文件或编辑 `## Gemini Added Memories` 部分：

```bash
rm ~/.gemini/GEMINI.md
```

## **常见问题**

| 问题 | 答案 |
|-----|------|
| **可以保存多少个事实？** | 理论上无限制，但出于性能考虑建议保持在合理范围内 |
| **保存的信息是私密的吗？** | 是的，信息存储在本地 `~/.gemini/GEMINI.md` 文件中 |
| **可以在多台计算机上同步吗？** | 不能自动同步，但您可以手动备份和恢复文件 |
| **删除的信息可以恢复吗？** | 需要备份文件才能恢复，否则无法恢复 |
| **信息有过期时间吗？** | 没有，信息会一直保存直到手动删除 |
