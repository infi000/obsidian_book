# CLI 命令

Gemini CLI 支持多个内置命令来帮助您管理会话、自定义界面和控制其行为。这些命令以正斜杠（`/`）、at 符号（`@`）或感叹号（`!`）作为前缀。

## 斜杠命令（`/`）

斜杠命令提供对 CLI 本身的元级别控制。

### 内置命令

- **`/bug`**
  - **描述：** 为 Gemini CLI 提交问题。默认情况下，问题在 Gemini CLI 的 GitHub 仓库中提交。在 `/bug` 之后输入的字符串将成为所提交问题的标题。可以使用 `.gemini/settings.json` 文件中的 `advanced.bugCommand` 设置修改默认 `/bug` 行为。

- **`/chat`**
  - **描述：** 保存并恢复对话历史记录以进行交互式分支对话状态，或从之后的会话恢复先前的状态。
  - **子命令：**
    - **`save`**
      - **描述：** 保存当前对话历史记录。您必须添加 `<tag>` 以标识对话状态。
      - **使用方法：** `/chat save <tag>`
      - **检查点位置详情：** 保存的聊天检查点的默认位置为：
        - Linux/macOS：`~/.gemini/tmp/<project_hash>/`
        - Windows：`C:\Users\<YourUsername>\.gemini\tmp\<project_hash>\`
        - **行为：** 聊天保存在项目特定的目录中，由您运行 CLI 的位置决定。因此，保存的聊天仅在在同一项目中工作时才可访问。
        - **注意：** 这些检查点用于手动保存和恢复对话状态。有关文件修改前自动创建的检查点，请参阅[检查点文档](/docs/cli/checkpointing)。
    - **`resume`**
      - **描述：** 从先前保存的对话恢复。
      - **使用方法：** `/chat resume <tag>`
      - **注意：** 您只能恢复在当前项目中保存的聊天。要恢复来自不同项目的聊天，必须从该项目的目录运行 Gemini CLI。
    - **`list`**
      - **描述：** 列出可用的标签以便恢复聊天状态。
      - **注意：** 此命令仅列出在当前项目中保存的聊天。由于聊天历史记录是项目范围的，保存在其他项目目录中的聊天将不会显示。
    - **`delete`**
      - **描述：** 删除已保存的对话检查点。
      - **使用方法：** `/chat delete <tag>`
    - **`share`**
      - **描述：** 将当前对话写入提供的 Markdown 或 JSON 文件。
      - **使用方法：** `/chat share file.md` 或 `/chat share file.json`。如果未提供文件名，则 CLI 将生成一个。

- **`/clear`**
  - **描述：** 清除终端屏幕，包括可见的会话历史记录和 CLI 中的回滚。基础会话数据（用于历史回调）可能会被保留，具体取决于确切的实现，但视觉显示会被清除。
  - **键盘快捷键：** 随时按 **Ctrl+L** 执行清除操作。

- **`/compress`**
  - **描述：** 用摘要替换整个聊天上下文。这样可以节省用于未来任务的令牌，同时保留所发生情况的高级摘要。

- **`/copy`**
  - **描述：** 将 Gemini CLI 生成的最后一个输出复制到剪贴板，便于共享或重用。
  - **注意：** 此命令需要安装特定于平台的剪贴板工具。
    - 在 Linux 上，需要 `xclip` 或 `xsel`。通常可以使用系统的软件包管理器安装它们。
    - 在 macOS 上，需要 `pbcopy`；在 Windows 上，需要 `clip`。这些工具通常在各自的系统上预安装。

- **`/directory`**（或 **`/dir`**）
  - **描述：** 管理工作区目录以支持多目录。
  - **子命令：**
    - **`add`**：
      - **描述：** 将目录添加到工作区。路径可以是绝对路径或相对于当前工作目录的路径。此外，还支持主目录的引用。
      - **使用方法：** `/directory add <path1>,<path2>`
      - **注意：** 在限制性沙箱配置文件中禁用。如果使用限制性沙箱配置文件，请在启动会话时使用 `--include-directories`。
    - **`show`**：
      - **描述：** 显示通过 `/directory add` 和 `--include-directories` 添加的所有目录。
      - **使用方法：** `/directory show`

- **`/editor`**
  - **描述：** 打开用于选择支持的编辑器的对话框。

- **`/extensions`**
  - **描述：** 列出当前 Gemini CLI 会话中的所有活动扩展。请参阅 [Gemini CLI 扩展](/docs/extensions)。

- **`/help`**（或 **`/?`**）
  - **描述：** 显示有关 Gemini CLI 的帮助信息，包括可用命令及其使用方法。

- **`/mcp`**
  - **描述：** 管理已配置的模型上下文协议 (MCP) 服务器。
  - **子命令：**
    - **`list`** 或 **`ls`**：
      - **描述：** 列出已配置的 MCP 服务器和工具。如果未指定子命令，这是默认操作。
    - **`desc`**
      - **描述：** 列出已配置的 MCP 服务器和工具及其描述。
    - **`schema`**：
      - **描述：** 列出已配置的 MCP 服务器和工具，包括描述和架构。
    - **`auth`**：
      - **描述：** 使用启用 OAuth 的 MCP 服务器进行身份验证。
      - **使用方法：** `/mcp auth <server-name>`
      - **详情：** 如果提供了 `<server-name>`，则启动该服务器的 OAuth 流程。如果未提供服务器名称，则列出所有支持 OAuth 身份验证的已配置服务器。
    - **`refresh`**：
      - **描述：** 重启所有 MCP 服务器并重新发现其可用工具。

- [**`/model`**](/docs/cli/model)
  - **描述：** 打开对话框以选择您的 Gemini 模型。

- **`/memory`**
  - **描述：** 管理 AI 的指令上下文（从 `GEMINI.md` 文件加载的分层内存）。
  - **子命令：**
    - **`add`**：
      - **描述：** 将以下文本添加到 AI 的内存中。使用方法：`/memory add <text to remember>`
    - **`show`**：
      - **描述：** 显示从所有 `GEMINI.md` 文件加载的当前分层内存的完整连接内容。这让您可以检查提供给 Gemini 模型的指令上下文。
    - **`refresh`**：
      - **描述：** 从在配置位置（全局、项目/祖先和子目录）找到的所有 `GEMINI.md` 文件重新加载分层指令内存。此命令使用最新的 `GEMINI.md` 内容更新模型。
    - **`list`**：
      - **描述：** 列出用于分层内存的 GEMINI.md 文件的路径。
    - **注意：** 有关 `GEMINI.md` 文件如何贡献于分层内存的更多详情，请参阅[CLI 配置文档](/docs/get-started/configuration)。

- **`/restore`**
  - **描述：** 将项目文件恢复到执行工具之前的状态。这对于撤销工具进行的文件编辑特别有用。如果运行时不带工具调用 ID，它将列出可以恢复的可用检查点。
  - **使用方法：** `/restore [tool_call_id]`
  - **注意：** 仅在通过[设置](/docs/get-started/configuration)配置检查点时可用。有关更多详情，请参阅[检查点文档](/docs/cli/checkpointing)。

- **`/resume`**
  - **描述：** 浏览并恢复以前的对话会话。打开交互式会话浏览器，您可以在其中搜索、过滤和选择自动保存的对话。
  - **功能：**
    - **会话浏览器：** 交互式界面，显示所有已保存的会话，包括时间戳、消息计数和第一条用户消息以供参考
    - **搜索：** 使用 `/` 在所有会话中搜索对话内容
    - **排序：** 按日期或消息计数排序会话
    - **管理：** 直接从浏览器删除不需要的会话
    - **恢复：** 选择任何会话以恢复并继续对话
  - **注意：** 所有对话都会在您聊天时自动保存 - 不需要手动保存。有关完整详情，请参阅[会话管理](/docs/cli/session-management)。

- [**`/settings`**](/docs/cli/settings)
  - **描述：** 打开设置编辑器以查看和修改 Gemini CLI 设置。
  - **详情：** 此命令提供了一个用户友好的界面来更改控制 Gemini CLI 行为和外观的设置。它等同于手动编辑 `.gemini/settings.json` 文件，但具有验证和指导以防止错误。有关可用设置的完整列表，请参阅[设置文档](/docs/cli/settings)。
  - **使用方法：** 只需运行 `/settings`，编辑器将打开。然后您可以浏览或搜索特定设置、查看其当前值并进行修改。某些设置的更改会立即应用，而其他设置需要重启。

- **`/stats`**
  - **描述：** 显示当前 Gemini CLI 会话的详细统计信息，包括令牌使用情况、缓存令牌节省（如果可用）和会话持续时间。注意：仅当使用缓存令牌时才显示缓存令牌信息，这发生在 API 密钥身份验证中，但目前不适用于 OAuth 身份验证。

- [**`/theme`**](/docs/cli/themes)
  - **描述：** 打开对话框，让您更改 Gemini CLI 的视觉主题。

- **`/auth`**
  - **描述：** 打开对话框，让您更改身份验证方法。

- **`/about`**
  - **描述：** 显示版本信息。提交问题时请分享此信息。

- [**`/tools`**](/docs/tools)
  - **描述：** 显示 Gemini CLI 中当前可用的工具列表。
  - **使用方法：** `/tools [desc]`
  - **子命令：**
    - **`desc`** 或 **`descriptions`**：
      - **描述：** 显示每个工具的详细描述，包括提供给模型的每个工具名称及其完整描述。
    - **`nodesc`** 或 **`nodescriptions`**：
      - **描述：** 隐藏工具描述，仅显示工具名称。

- **`/privacy`**
  - **描述：** 显示隐私通知并允许用户选择是否同意收集其数据以改进服务。

- **`/quit`**（或 **`/exit`**）
  - **描述：** 退出 Gemini CLI。

- **`/vim`**
  - **描述：** 切换 vim 模式的开关。启用 vim 模式后，输入区域支持 NORMAL 和 INSERT 模式中的 vim 风格导航和编辑命令。
  - **功能：**
    - **NORMAL 模式：** 使用 `h`、`j`、`k`、`l` 导航；使用 `w`、`b`、`e` 按词跳转；使用 `0`、`$`、`^` 转到行首/行尾；使用 `G`（或 `gg` 转到第一行）转到特定行
    - **INSERT 模式：** 标准文本输入，按 escape 返回 NORMAL 模式
    - **编辑命令：** 使用 `x` 删除，使用 `c` 更改，使用 `i`、`a`、`o`、`O` 插入；复杂操作如 `dd`、`cc`、`dw`、`cw`
    - **计数支持：** 在命令前加数字（例如 `3h`、`5w`、`10G`）
    - **重复最后一个命令：** 使用 `.` 重复最后一个编辑操作
    - **持久化设置：** Vim 模式偏好保存到 `~/.gemini/settings.json`，并在会话间恢复
  - **状态指示器：** 启用时，在页脚中显示 `[NORMAL]` 或 `[INSERT]`

- **`/init`**
  - **描述：** 为帮助用户轻松创建 `GEMINI.md` 文件，此命令分析当前目录并生成定制的上下文文件，使他们更容易为 Gemini 代理提供项目特定的指令。

### 自定义命令

自定义命令允许您为最常用的提示创建个性化快捷方式。有关如何创建、管理和使用它们的详细说明，请参阅专门的[自定义命令文档](/docs/cli/custom-commands)。

## 输入提示快捷键

这些快捷键直接应用于用于文本操作的输入提示。

- **撤销：**
  - **键盘快捷键：** 按 **Ctrl+z** 撤销输入提示中的最后一个操作。

- **重做：**
  - **键盘快捷键：** 按 **Ctrl+Shift+Z** 重做输入提示中最后一个撤销的操作。

## At 命令（`@`）

At 命令用于将文件或目录的内容作为对 Gemini 的提示的一部分包括在内。这些命令包括 git 感知过滤。

- **`@<path_to_file_or_directory>`**
  - **描述：** 将指定文件或文件的内容注入当前提示中。这对于询问关于特定代码、文本或文件集合的问题很有用。
  - **示例：**
    - `@path/to/your/file.txt 解释这个文本。`
    - `@src/my_project/ 总结此目录中的代码。`
    - `这个文件是关于什么的？@README.md`
  - **详情：**
    - 如果提供了单个文件的路径，则读取该文件的内容。
    - 如果提供了目录的路径，该命令尝试读取该目录及任何子目录内的文件内容。
    - 路径中的空格应使用反斜杠转义（例如 `@My\ Documents/file.txt`）。
    - 该命令在内部使用 `read_many_files` 工具。获取内容，然后在将其发送到 Gemini 模型之前将其插入到查询中。
    - **Git 感知过滤：** 默认情况下，git 忽略的文件（如 `node_modules/`、`dist/`、`.env`、`.git/`）被排除。此行为可以通过 `context.fileFiltering` 设置进行更改。
    - **文件类型：** 该命令适用于基于文本的文件。虽然它可能尝试读取任何文件，但二进制文件或非常大的文件可能会被基础 `read_many_files` 工具跳过或截断，以确保性能和相关性。该工具指示是否跳过了文件。
  - **输出：** CLI 将显示工具调用消息，指示使用了 `read_many_files`，以及说明状态和已处理路径的消息。

- **`@`（单独的 at 符号）**
  - **描述：** 如果您键入单个 `@` 符号而没有路径，则查询按原样传递给 Gemini 模型。如果您在提示中专门讨论 `@` 符号，这可能很有用。

### `@` 命令的错误处理

- 如果在 `@` 之后指定的路径未找到或无效，将显示错误消息，查询可能不会发送到 Gemini 模型，或者将不含文件内容被发送。
- 如果 `read_many_files` 工具遇到错误（例如权限问题），这也将被报告。

## Shell 模式和传递命令（`!`）

`!` 前缀让您可以直接从 Gemini CLI 中与系统的 shell 交互。

- **`!<shell_command>`**
  - **描述：** 在 Linux/macOS 上使用 `bash` 或在 Windows 上使用 `powershell.exe -NoProfile -Command` 执行给定的 `<shell_command>`（除非您覆盖 `ComSpec`）。命令的任何输出或错误都会显示在终端中。
  - **示例：**
    - `!ls -la`（执行 `ls -la` 并返回到 Gemini CLI）
    - `!git status`（执行 `git status` 并返回到 Gemini CLI）

- **`!`（切换 shell 模式）**
  - **描述：** 单独键入 `!` 可切换 shell 模式。
    - **进入 shell 模式：**
      - 激活时，shell 模式使用不同的颜色和"Shell 模式指示器"。
      - 在 shell 模式中，您键入的文本被直接解释为 shell 命令。
    - **退出 shell 模式：**
      - 退出时，UI 恢复为标准外观，Gemini CLI 正常行为恢复。

- **所有 `!` 使用的警告：** 您在 shell 模式中执行的命令具有与直接在终端中运行它们相同的权限和影响。

- **环境变量：** 当命令通过 `!` 或在 shell 模式中执行时，`GEMINI_CLI=1` 环境变量在子进程的环境中被设置。这允许脚本或工具检测它们是否在 Gemini CLI 中运行。
