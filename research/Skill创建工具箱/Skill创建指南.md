# Skill 创建指南

这是一个**Skill 创建的完整指南**。按照这个规范，你可以自己创建任何 Skill。

## 🎯 Skill 的核心结构

### 1️⃣ 标题和简介（必须）

```markdown
# Skill 名称

Skill 的简短描述（一句话说明这个 Skill 是做什么的）
```

**例子：**
```markdown
# 知识库 Skill 生成器

这是一个知识库型 Skill 的自动生成工具。
```

### 2️⃣ 功能说明（必须）

```markdown
## 🎯 Skill 的功能

这个 Skill 可以帮助你：
- 📖 **功能1** - 简要说明
- 🔧 **功能2** - 简要说明
- 📝 **功能3** - 简要说明
```

**例子：**
```markdown
## 🎯 Skill 的功能

这个 Skill 可以帮助你：
- 📖 自动从项目中提取信息
- 🔧 识别技术栈和架构
- 📝 生成完整的知识库文档
```

### 3️⃣ 使用方法（必须）

```markdown
## 📋 使用方法

### 第 1 步：【第一步做什么】

说明第一步的具体操作

### 第 2 步：【第二步做什么】

说明第二步的具体操作

### 第 3 步：【第三步做什么】

说明第三步的具体操作
```

**例子：**
```markdown
## 📋 使用方法

### 第 1 步：提供项目路径

告诉我你的项目在哪里

### 第 2 步：我会自动分析

自动读取 README、package.json 等文件

### 第 3 步：获取结果

得到生成的 Skill
```

### 4️⃣ 详细说明（可选）

根据需要，添加更多部分来解释功能、特性、注意事项等。

```markdown
## 💡 特性

- ✅ 特性1
- ✅ 特性2

## ⚠️ 注意事项

- 注意项1
- 注意项2

## 🚀 立即开始

【行动指令】
```

## 📝 Skill 编写的最佳实践

### ✅ 清晰的结构

使用 Markdown 标题、表格、列表来组织信息。

```markdown
# Skill 名称

## 🎯 功能
- 清晰的要点列表

## 📋 使用方法
### 第 1 步
### 第 2 步
### 第 3 步

## 💡 特性
- ✅ 特性1
- ✅ 特性2

## 🚀 立即开始
具体操作指令
```

### ✅ 使用 Emoji 增强可读性

```markdown
📖 知识相关
🎯 目标相关
📋 列表相关
🚀 开始相关
💡 建议相关
✅ 完成相关
⚠️ 警告相关
```

### ✅ 清晰的行动指令

每个 Skill 都应该清楚地告诉用户该做什么。

```markdown
## 🚀 现在就开始

【告诉用户该做什么】

例如：
```
【具体的输入格式】
```

结果会是什么
```

### ✅ 具体的例子

用实际的例子说明 Skill 的效果。

```markdown
## 💡 使用示例

**输入：**
```
项目路径：/Users/john/my-project
```

**结果：**
```
生成的 Skill 包含：
- 项目介绍
- 开发规范
- 最佳实践
```
```

## 🔧 不同类型的 Skill 模板

### 知识库型 Skill

```markdown
# 【项目名】知识库

这是一个关于【项目】的知识库。

## 🎯 Skill 的功能

- 📖 快速了解【项目】
- 🎨 参考【领域】的规范
- 🔍 查阅【项目】的最佳实践

## 📑 快速导航

| 内容 | 链接 |
|-----|------|
| 介绍 | [[intro]] |
| 规范 | [[standards]] |
| 实践 | [[practices]] |

## 📖 完整目录

- 项目介绍
- 开发规范
- 最佳实践
- 开发指南
- 常见问题

## 🚀 使用方式

1. 浏览目录，找到你需要的内容
2. 点击链接查看详细信息
3. 按照指导进行开发
```

```markdown
- 💡 最佳实践和指导

## 📋 工作流步骤

### 第 1 步：【步骤1】
- [ ] 检查项 1
- [ ] 检查项 2

### 第 2 步：【步骤2】
- [ ] 检查项 1
- [ ] 检查项 2

### 第 3 步：【步骤3】
- [ ] 检查项 1
- [ ] 检查项 2

## 🚀 现在就开始

【具体操作】
```

## ✨ Skill 编写技巧

### 1. 开门见山

第一句话就说明这个 Skill 是做什么的。

```markdown
❌ 这是一个很有用的工具...
✅ 这是一个代码审查工作流 Skill。
```

### 2. 使用表格组织复杂信息

```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 内容 | 内容 | 内容 |
```

### 3. 用列表代替段落

```markdown
❌ 这个 Skill 有很多功能，包括...

✅ 这个 Skill 的功能：
- 功能1
- 功能2
- 功能3
```

### 4. 提供具体例子

```markdown
❌ 你可以用这个...

✅ 例子：
```
【具体的例子】
```
```

### 5. 清晰的行动指令

```markdown
❌ 你可以告诉我...

✅ 现在告诉我：
```
【具体的输入格式】
```
```
