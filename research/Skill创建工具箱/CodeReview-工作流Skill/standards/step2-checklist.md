# Step 2 检查清单：检查规范

代码是否遵守了规范约定。

---

## 代码风格

- [ ] 变量声明合规（const/let，禁止 var）
- [ ] 使用了 arrow function
- [ ] 代码格式一致（缩进、空格）
- [ ] 没有拼写错误
- [ ] 注释清晰且必要
- [ ] 没有 console.log / debugger

## 命名规范

- [ ] 文件名符合规范（PascalCase/camelCase）
- [ ] 变量名清晰有意义
- [ ] 函数名描述功能
- [ ] 常量用 UPPER_SNAKE_CASE
- [ ] 没有使用单个字母命名（除了循环变量 i/j）

## TypeScript

- [ ] 没有使用 any 类型
- [ ] 类型定义完整
- [ ] 接口/类型命名正确
- [ ] 泛型使用恰当

## 导入和依赖

- [ ] 导入排序正确（内置 > 第三方 > 本地）
- [ ] 没有未使用的导入
- [ ] 没有循环依赖
- [ ] 依赖版本合理

## 代码结构

- [ ] 函数长度合理（建议 <20 行）
- [ ] 模块职责单一
- [ ] 代码可读性好
- [ ] 没有重复代码
