# Step 3 检查清单：检查逻辑

代码逻辑是否正确，是否有 bug。

---

## 业务逻辑

- [ ] 逻辑实现了需求
- [ ] 处理了边界情况（null、undefined、empty）
- [ ] 没有逻辑漏洞
- [ ] 条件判断准确
- [ ] 循环逻辑正确

## 错误处理

- [ ] 处理了 API 失败
- [ ] 处理了网络超时
- [ ] 处理了用户输入错误
- [ ] 错误提示清晰
- [ ] 有必要的 try-catch

## 数据流

- [ ] 数据来源清晰
- [ ] 数据流向正确
- [ ] 没有数据泄露
- [ ] 状态更新正确
- [ ] 没有修改 props

## 异步操作

- [ ] Promise/async-await 正确
- [ ] 没有竞态条件
- [ ] 清理工作完整（useEffect cleanup）
- [ ] 取消机制正确

## 性能和质量

- [ ] 没有无限循环
- [ ] 没有频繁重新渲染
- [ ] 没有内存泄漏
- [ ] 算法复杂度合理
- [ ] 没有明显的性能问题

## 常见 Bug 模式

- [ ] 没有闭包陷阱
- [ ] 没有异步陷阱
- [ ] 没有引用类型问题
- [ ] 没有副作用问题
