# Step 1 检查清单：理解需求

快速检查清单，确保你充分理解了这个 PR/MR。

---

## PR 基本信息

- [ ] PR 有清晰的标题
- [ ] 标题说明了改动内容
- [ ] PR 有描述说明改动原因
- [ ] PR 链接了相关 issue 或需求
- [ ] PR 关联了正确的分支（如 main/develop）

## 改动范围

- [ ] 了解改动了哪些文件
- [ ] 改动行数在合理范围（建议 <500 行）
- [ ] 没有无关的改动
- [ ] 清楚改动的类型（新增/修改/删除）

## 风险评估

- [ ] 确认了改动的核心目的
- [ ] 确认了可能影响的模块
- [ ] 确认了需要特别关注的地方
- [ ] 评估了改动的风险等级

## 需求理解

- [ ] 理解了需求的背景
- [ ] 理解了为什么要做这个改动
- [ ] 理解了改动的范围和边界
- [ ] 知道改动会影响什么
