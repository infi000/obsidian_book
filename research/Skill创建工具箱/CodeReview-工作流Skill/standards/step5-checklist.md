# Step 5 检查清单：整理反馈

汇总审查意见成标准的反馈。

---

## 反馈结构

- [ ] 有整体评价（✅ 好 / ⚠️ 一般 / ❌ 差）
- [ ] 整体评价有理由说明
- [ ] 问题分类清晰（🔴 / 🟡 / 🟢）
- [ ] 有优点说明（鼓励）
- [ ] 有下一步说明

## Blocking 问题

- [ ] 列出了所有必须修改的问题
- [ ] 每个问题都有具体位置
- [ ] 每个问题都有改进建议
- [ ] 有参考规范或最佳实践链接

## Warning 建议

- [ ] 列出了应该修改的建议
- [ ] 每个建议都清晰明确
- [ ] 说明了为什么这样做更好
- [ ] 没有过度挑剔

## Info 信息

- [ ] 列出了参考信息
- [ ] 信息有用且相关
- [ ] 没有多余的信息

## 反馈质量

- [ ] 语气友善和尊重
- [ ] 反馈具体而不模糊
- [ ] 给出了改进建议
- [ ] 引用了规范或最佳实践
- [ ] 没有拼写错误
- [ ] 易于理解

## 分级准确

- [ ] Blocking 问题分级准确
- [ ] Warning 建议分级准确
- [ ] Info 信息分级准确
- [ ] 没有过度 Blocking

---

✅ **Step 5 完成，Code Review 工作流结束！**
