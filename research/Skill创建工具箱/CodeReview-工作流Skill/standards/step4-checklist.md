# Step 4 检查清单：检查影响

评估改动对其他部分的影响。

---

## 依赖关系

- [ ] 确认谁依赖这个模块
- [ ] 改动了什么接口或 API
- [ ] 是否破坏了后向兼容性
- [ ] 相关模块是否需要同步改动
- [ ] 导出接口是否需要更新

## 测试覆盖

- [ ] 有新增或修改的测试
- [ ] 测试覆盖了改动的代码
- [ ] 现有测试不会失败
- [ ] 测试覆盖率合理

## 性能影响

- [ ] 没有性能下降
- [ ] 加载时间没增加
- [ ] 内存占用合理
- [ ] 大数据量下仍高效

## 安全影响

- [ ] 没有新的安全风险
- [ ] 用户输入都验证了
- [ ] 敏感信息保护好了
- [ ] 没有 XSS/CSRF/SQL 注入风险
- [ ] 权限检查完整

## 其他影响

- [ ] 文档需要更新吗？
- [ ] API 文档需要更新吗？
- [ ] 数据库 schema 需要改动吗？
- [ ] 部署有特殊要求吗？
- [ ] 有回滚计划吗？
