## 📋 规范等级说明

| 标记 | 含义 | 示例 |
|-----|------|------|
| 🔴 **MUST** | 必须遵守，强制执行 | 必须使用 TypeScript |
| 🟡 **SHOULD** | 强烈建议，代码审查会检查 | 应该使用 functional components |
| 🟢 **MAY** | 可选建议，根据项目情况 | 可选使用 storybook |
