```
特点：
  ├─ 🎯 用途: 代码审查全流程
  ├─ 🔄 结构: SKILL.md + 5 个顺序步骤 + 支撑清单
  ├─ 📍 关系: 步骤有明确的执行顺序
  ├─ 📋 内容: 14 个文件
  │   ├─ workflow 目录（5 个步骤）
  │   ├─ standards 目录（3 个检查清单）
  │   ├─ templates 目录（反馈模板）
  │   └─ rules 目录（规范指南）
  │
  ├─ 👥 用户: 代码审查者、PR 把关人、质量控制
  └─ ⏱️ 使用方式: 按照 5 步流程逐步执行
```

**包含的审查流程**：

```
Step 1️⃣ 理解上下文
  └─ 读 PR、理解背景、确定焦点

Step 2️⃣ 检查代码质量
  ├─ 代码规范（命名、风格、TypeScript）
  ├─ 逻辑检查（清晰、正确、测试）
  └─ 参考: code-quality-checklist.md

Step 3️⃣ 检查安全性和性能
  ├─ 安全检查（XSS、CSRF、敏感信息等）
  ├─ 性能检查（渲染、网络、包体积）
  └─ 参考: security-checklist.md + performance-checklist.md

Step 4️⃣ 整理反馈意见
  ├─ 分类: Blocking / Should Fix / Nice to Have
  ├─ 撰写: 清晰、具体、有建议
  └─ 参考: feedback-guidelines.md + review-feedback-template.md

Step 5️⃣ 最终检查和提交
  ├─ 质量检查
  ├─ 提交反馈
  └─ 后续跟进
```
