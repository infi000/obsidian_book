# 安全和性能检查清单

在 [[../../工作流型Skill/workflow/step3-check-security-and-performance|Step 3 - 检查质量/安全/性能]] 时使用。

## 🔐 安全检查清单

### 关键安全问题（必须检查）

- [ ] **XSS 防护**
  - [ ] 有没有使用 `dangerouslySetInnerHTML` 而没有清理？
  - [ ] 用户输入是否被直接插入 HTML？
  - 参考：[[../../知识库型Skill/best-practices/security-checklist#xss|安全指南 - XSS 防护]]

- [ ] **认证/授权**
  - [ ] 是否验证了用户权限？（后端必须验证）
  - [ ] 只在前端隐藏敏感功能吗？（应该后端检查）
  - [ ] 认证 token 安全吗？（短期有效）

- [ ] **敏感信息处理**
  - [ ] 有没有记录密码、token、密钥？
  - [ ] 敏感数据存储在 localStorage 吗？（不应该）
  - [ ] 敏感数据在 URL 中吗？（不应该）

- [ ] **数据库安全**
  - [ ] 使用了参数化查询吗？（不是字符串拼接）
  - [ ] 有 SQL 注入风险吗？

- [ ] **依赖安全**
  - [ ] 新依赖可信吗？
  - [ ] 有已知漏洞吗？（运行 npm audit）

---

## ⚡ 性能检查清单

### 常见性能问题

- [ ] **不必要的重新渲染**
  - [ ] 组件是否频繁重新渲染？
  - [ ] 是否在 JSX 中创建新对象或数组？
  - [ ] 是否应该使用 useMemo 或 useCallback？
  - 参考：[[../../知识库型Skill/best-practices/performance-tips|性能优化指南]]

- [ ] **大数据列表处理**
  - [ ] 列表有很多项（>100）吗？
  - [ ] 是否使用了虚拟滚动？
  - [ ] 是否可以用分页代替？

- [ ] **API 请求**
  - [ ] 有不必要的重复请求吗？
  - [ ] 是否有请求缓存？
  - [ ] 是否应该批量请求？

- [ ] **依赖大小**
  - [ ] 新依赖是否太重？
  - [ ] 是否有更小的替代方案？
  - [ ] 是否可以用 tree-shaking？

- [ ] **算法效率**
  - [ ] 时间复杂度合理吗？
  - [ ] 有没有 O(n²) 的嵌套循环？
  - [ ] 可以优化吗？
