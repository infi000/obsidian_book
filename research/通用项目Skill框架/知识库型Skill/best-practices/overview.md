# 最佳实践总览

欢迎来到最佳实践中心。这里收集了项目中推荐的开发做法。

## 🎯 最佳实践快速索引

| 主题 | 用途 | 链接 |
|-----|-----|------|
| **常见模式** | 项目中常用的设计模式和代码模式 | [[common-patterns\|常见模式]] |
| **性能优化** | 如何优化应用性能 | [[performance-tips\|性能优化]] |
| **安全检查** | 项目中需要关注的安全问题 | [[security-checklist\|安全检查]] |

## 📖 为什么关注最佳实践？

- ✅ **避免常见错误** - 学习他人的经验教训
- ✅ **提高代码质量** - 应用行业标准做法
- ✅ **性能更好** - 优化应用运行效率
- ✅ **更安全** - 防止安全漏洞
- ✅ **易于维护** - 代码更容易理解和修改

## 使用方式

### 开发时参考最佳实践

1. 在 [[common-patterns|常见模式]] 中查看是否有类似的场景
2. 在 [[performance-tips|性能优化]] 中检查是否有相关的优化建议
3. 在 [[security-checklist|安全检查]] 中验证是否有安全隐患

### Code Review 时参考最佳实践

使用最佳实践来指导 Code Review，确保代码不仅符合规范，还符合最佳实践。

参考 [[../../工作流型Skill/SKILL|代码审查 Skill]]。
