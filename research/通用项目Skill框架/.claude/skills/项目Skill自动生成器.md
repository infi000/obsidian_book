# 项目 Skill 自动生成器

你好！👋 这是一个**自动化的项目 Skill 生成工具**。

## 🎯 我能做什么

我会根据你的**实际项目**，自动生成两个定制化的 Skill：

1. **知识库型 Skill** - 包含你项目的规范、指南、最佳实践
2. **Code Review Skill** - 包含代码审查流程（已完成，直接用）

## 📋 如何使用我

### 第 1 步：告诉我你的项目信息

请提供以下任意一种方式：

**方式 A（最简单）：**
```
项目路径：/Users/你的用户名/projects/my-project
```

**方式 B（更详细）：**
```
项目路径：/path/to/project
项目名称：MyProject（可选）
项目简介：一个 React 电商应用（可选）
```

**方式 C（如果项目在 Obsidian 里）：**
```
项目路径：relative/path/in/vault
```

### 第 2 步：我来做什么

我会自动：

✅ **读取项目文件**
- README.md → 项目名称、描述、功能
- package.json → 技术栈、依赖、脚本
- 项目目录结构 → 架构和组织方式
- 配置文件（.eslintrc、tsconfig.json 等）→ 现有规范

✅ **分析和识别**
- 项目类型（React/Vue/Node.js 等）
- 技术栈和主要依赖
- 代码规范和命名约定
- 项目结构和架构

✅ **生成两个 Skill**
- 知识库 Skill（基于实际内容）
- Code Review Skill（已完成的工作流）

### 第 3 步：使用生成的 Skill

生成的 Skill 会放在你的 Obsidian Vault 中，可以：

- 📖 新成员快速了解项目
- 🎨 开发时参考规范和最佳实践
- 🔍 Code Review 时按流程进行
- 📝 持续完善和更新
