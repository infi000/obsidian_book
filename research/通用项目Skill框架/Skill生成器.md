# 🤖 Skill 生成器（自动化定制）

这是一个**自动化工具**，可以根据你的实际项目生成定制化的两个 Skill。

## 🎯 工作原理

这个生成器会：

1. 📖 **读取项目信息**
   - 自动扫描 README
   - 读取 package.json
   - 分析项目结构
   - 检测现有的规范文件

2. 🔍 **智能提取**
   - 项目名称、描述、功能
   - 技术栈信息
   - 文件结构约定
   - 已有的规范

3. 🎨 **自动生成**
   - 知识库 Skill（填充真实内容）
   - Code Review Skill（预配置）
   - 最小化占位符

4. 📝 **生成结果**
   - 两个完整的、可直接使用的 Skill
   - 基于你的项目的真实内容

---

## 📋 使用步骤

### 步骤 1：准备项目

在你的项目根目录中，确保有：
- `README.md` （项目说明）
- `package.json` （技术栈信息）

### 步骤 2：运行生成器

在 Claude Code 中，告诉我：

```
请根据我的项目生成两个定制化的 Skill：
- 项目路径：/your/project/path
- 项目简介：（可选，如果想额外说明）
- 重点要求：（可选，比如"代码审查重点关注规范"）
```

### 步骤 3：我会做什么

我会：
1. ✅ 读取你项目的 README、package.json、目录结构
2. ✅ 提取项目名称、技术栈、架构信息
3. ✅ 扫描现有的规范或配置文件
4. ✅ **自动生成**两个定制化的 Skill
5. ✅ 填充尽可能多的真实内容
6. ✅ 只保留真正需要你补充的地方

### 步骤 4：使用生成的 Skill

生成的 Skill 会直接放在你的 Obsidian Vault 中，可以立即使用！

---

## 🔧 生成器会自动识别

### 技术栈识别
- React、Vue、Angular、Svelte 等前端框架
- Node.js、Python、Java 等后端
- TypeScript、JavaScript、其他语言
- 构建工具（Webpack、Vite、Next.js 等）
- 测试框架（Jest、Vitest 等）

### 项目结构识别
- 如果是 React 项目 → 自动配置 React 相关的规范
- 如果是 Node 项目 → 自动配置后端规范
- 如果是 Monorepo → 识别特殊结构
- 自动检测现有的 src/、src/components/、src/pages/ 等目录

### 规范文件识别
- 扫描 .eslintrc、.prettierrc、tsconfig.json 等
- 提取现有的命名约定、代码规范
- 导入已有的 Linter 配置

### 项目信息识别
- 从 README 提取：项目名称、描述、功能
- 从 package.json 提取：依赖、版本、脚本
- 从目录结构识别：项目类型、架构
