## 核心概念

### 无头浏览器（Headless Browser）定义

无头浏览器是指**不提供图形用户界面（GUI）**的浏览器实现，完全通过编程接口进行控制。它保留了完整的浏览器功能，但以自动化方式运行。

**关键特性**：
- 无图形界面，资源占用低
- 支持 JavaScript 执行
- 完整的 DOM、CSS 渲染
- 网络请求/响应拦截
- Cookie 和 Session 管理
- 截图、PDF 导出

### 扫码登录（QR Code Login）原理

扫码登录是一种**无密码认证方式**，用户通过扫描二维码完成身份验证。

**核心流程**：
```
用户请求登录页面 → 生成QR码 → 用户扫描 → 移动端确认 → 服务器返回Token → 浏览器建立会话
```

## 技术原理

### 1. 扫码登录完整流程

```
┌─────────────────────────────────────────────────────────────────┐
│                         扫码登录架构流程                          │
└─────────────────────────────────────────────────────────────────┘

┌──────────────┐         ┌──────────────┐         ┌──────────────┐
│   PC浏览器   │         │   登录服务器  │         │   移动设备   │
│  (Headless)  │         │   Auth Server │         │   (Scanning) │
└──────────────┘         └──────────────┘         └──────────────┘
      │                         │                        │
      ├─ 1. 请求登录页面 ─────→│                        │
      │                         │                        │
      │                  ┌─────────────┐                 │
      │                  │ 生成Session │                 │
      │                  │ 生成QR Code  │                 │
      │                  └─────────────┘                 │
      │←─ 2. 返回QR码 ────────│                        │
      │                         │                        │
      │  3. 截取/识别QR码      │                        │
      │                         │                        │
      │  4. 发送QR码数据───────→│←─ 5. 用户扫描 ───────│
      │                         │                        │
      │                         │  6. 验证身份+确认────→│
      │                         │                        │
      │←─ 7. 返回Token/Session ID                        │
      │                         │
      │  8. 自动设置Cookie                               │
      │     建立会话                                      │
      │
      └─ 9. 成功登录, 可继续自动化操作
```

### 2. 与传统登录的区别

| 维度 | 扫码登录 | 用户名密码登录 | OAuth2.0 | 二次验证 |

| **用户体验** | 好（快速） | 一般 | 好（跳转认证） | 一般（需多步骤） |
| **实现复杂度** | 中 | 低 | 高 | 中 |
| **无头浏览器支持** | 需手动模拟 | 直接可用 | 需配合处理 | 可配合二维码 |
| **防爬虫能力** | 很强 | 弱 | 中 | 很强 |
| **分布式场景** | 优秀 | 一般 | 优秀 | 优秀 |

### 3. 无头浏览器在扫码登录中的角色

```
无头浏览器的关键职责：
├─ 1. 页面加载与解析
│   └─ 完整渲染登录页面
│   └─ 执行页面中的JavaScript代码
│
├─ 2. QR码提取
│   └─ 截图页面中的QR码
│   └─ 使用OCR或QR解码库识别
│   └─ 提取embedded token/session信息
│
├─ 3. 会话管理
│   └─ 自动设置Cookie
│   └─ 管理HTTP Headers
│   └─ 处理重定向
│
├─ 4. 动态等待
│   └─ 轮询检查登录状态
│   └─ 监听WebSocket消息
│   └─ 处理异步验证
│
└─ 5. 后续自动化
    └─ 导航至目标页面
    └─ 执行业务操作
    └─ 获取数据或截图
```

## 主流方案对比

### 1. Puppeteer

**简介**：由Chrome DevTools团队维护，专门为Node.js设计

**优点**：
- 专门针对Chrome/Chromium优化
- 简洁的API设计
- 性能稳定，资源占用低
- 良好的文档和生态
- 支持调试协议（CDP）直连

**缺点**：
- 仅支持Node.js
- 跨浏览器支持有限（Firefox/Edge支持较弱）
- 不支持Python官方版本

**适用场景**：
- 爬虫开发
- 截图/PDF生成
- 性能测试

**安装与基础使用**：

```bash
npm install puppeteer
```

```javascript
const puppeteer = require('puppeteer');

(async () => {
  const browser = await puppeteer.launch({
    headless: true,
    args: ['--no-sandbox']
  });
  const page = await browser.newPage();
  await page.goto('https://example.com');
  await browser.close();
})();
```

### 2. Playwright

**简介**：微软开发的新一代跨浏览器自动化框架

**优点**：
- 支持多种编程语言（JavaScript、Python、Java、C#）
- 三大浏览器全支持（Chromium、Firefox、WebKit）
- 内置等待机制，减少不稳定性
- 更快的执行速度
- 现代化API设计
- 详细的事件监听

**缺点**：
- 资源占用相对较大（支持多浏览器）
- 社区相对较新
- 依赖较多

**适用场景**：
- 跨浏览器兼容性测试
- 现代化自动化测试框架
- 多语言项目集成

```javascript
// qr-login.js
const { chromium } = require('playwright');
const fs = require('fs');
const path = require('path');
const jsQR = require('jsqr');
const Jimp = require('jimp');

class HeadlessQRLogin {
  constructor(options = {}) {
    this.loginUrl = options.loginUrl || 'https://example.com/login';
    this.pollInterval = options.pollInterval || 1000; // 轮询间隔(ms)
    this.maxWaitTime = options.maxWaitTime || 60000; // 最大等待时间
    this.browser = null;
    this.page = null;
    this.context = null;
  }

  /**
   * 初始化浏览器
   */
  async init() {
    this.browser = await chromium.launch({
      headless: true,
      args: [
        '--no-sandbox',
        '--disable-setuid-sandbox',
        '--disable-dev-shm-usage'
      ]
    });

    // 创建隔离的浏览器context（用于会话管理）
    this.context = await this.browser.newContext({
      ignoreHTTPSErrors: true,
      viewport: { width: 1920, height: 1080 },
      userAgent: 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36'
    });

    this.page = await this.context.newPage();

    // 添加请求/响应拦截（可选）
    await this.setupInterceptors();
  }

  /**
   * 设置网络拦截器
   */
  async setupInterceptors() {
    // 监听所有请求
    this.page.on('request', request => {
      console.log('>>', request.method(), request.url());
    });

    // 监听所有响应
    this.page.on('response', response => {
      if (response.status() >= 400) {
        console.log('<<', response.status(), response.url());
      }
    });

    // 监听console消息
    this.page.on('console', msg => {
      console.log('PAGE LOG:', msg.type(), msg.text());
    });

    // 监听页面崩溃
    this.page.on('error', err => {
      console.error('PAGE ERROR:', err);
    });
  }

  /**
   * 导航至登录页面
   */
  async goToLoginPage() {
    try {
      console.log('正在导航至登录页面...');
      await this.page.goto(this.loginUrl, {
        waitUntil: 'networkidle',
        timeout: 30000
      });
      console.log('页面加载完成');
      return true;
    } catch (error) {
      console.error('导航失败:', error.message);
      return false;
    }
  }

  /**
   * 提取QR码
   */
  async extractQRCode() {
    try {
      console.log('正在截取QR码...');

      // 查找QR码元素
      const qrElement = await this.page.$('img[alt*="二维码"], img[class*="qr"]');

      if (!qrElement) {
        throw new Error('页面中未发现QR码元素');
      }

      // 获取QR码图片
      const screenshotBuffer = await qrElement.screenshot();

      // 使用Jimp识别QR码
      const image = await Jimp.read(screenshotBuffer);
      const imageData = image.bitmap;

      // 尝试识别QR码
      const code = jsQR.default(
        new Uint8ClampedArray(imageData.data),
        imageData.width,
        imageData.height
      );

      if (code && code.data) {
        console.log('QR码识别成功:', code.data);
        return code.data;
      } else {
        throw new Error('QR码识别失败');
      }
    } catch (error) {
      console.error('提取QR码失败:', error.message);
      return null;
    }
  }

  /**
   * 轮询等待登录完成
   */
  async waitForLogin(maxWait = this.maxWaitTime) {
    const startTime = Date.now();

    return new Promise(async (resolve, reject) => {
      const checkLogin = async () => {
        try {
          // 方案A: 检查特定元素消失（QR码框消失）
          const qrContainer = await this.page.$('.qr-login-container');
          if (!qrContainer) {
            console.log('QR码容器已消失，可能已登录');
            // 等待页面稳定
            await this.page.waitForNavigation({
              waitUntil: 'networkidle',
              timeout: 5000
            }).catch(() => null);
            resolve(true);
            return;
          }

          // 方案B: 检查cookie变化
          const cookies = await this.context.cookies();
          const hasAuthCookie = cookies.some(c =>
            c.name.includes('token') ||
            c.name.includes('session') ||
            c.name.includes('auth')
          );

          if (hasAuthCookie) {
            console.log('检测到授权cookie，登录成功');
            resolve(true);
            return;
          }

          // 方案C: 监听XHR响应
          // (在setupInterceptors中已实现)

          // 超时检查
          if (Date.now() - startTime > maxWait) {
            reject(new Error(`登录超时(${maxWait}ms)`));
            return;
          }

          // 继续轮询
          setTimeout(checkLogin, this.pollInterval);

        } catch (error) {
          reject(error);
        }
      };

      // 开始轮询
      checkLogin();
    });
  }

  /**
   * 使用WebSocket监听登录状态（高级）
   */
  async setupWebSocketListener(wsUrl) {
    return new Promise((resolve, reject) => {
      this.page.evaluateHandle((wsUrl) => {
        return new Promise((resolve) => {
          const ws = new WebSocket(wsUrl);

          ws.onmessage = (event) => {
            const data = JSON.parse(event.data);
            if (data.type === 'LOGIN_SUCCESS') {
              resolve(data);
            }
          };

          ws.onerror = () => reject(new Error('WebSocket连接失败'));
        });
      }, wsUrl).then(resolve).catch(reject);
    });
  }

  /**
   * 执行完整登录流程
   */
  async login() {
    try {
      // 1. 初始化浏览器
      await this.init();
      console.log('✓ 浏览器已初始化');

      // 2. 导航至登录页面
      const navigated = await this.goToLoginPage();
      if (!navigated) throw new Error('无法访问登录页面');
      console.log('✓ 已导航至登录页面');

      // 3. 提取QR码
      const qrData = await this.extractQRCode();
      if (!qrData) throw new Error('QR码提取失败');
      console.log('✓ QR码已成功识别');

      // 4. 等待用户扫描并确认
      console.log('\n等待用户扫描QR码并确认...');
      console.log(`QR码数据: ${qrData}\n`);

      await this.waitForLogin();
      console.log('✓ 用户已成功登录');

      // 5. 验证登录状态
      const isLoggedIn = await this.verifyLogin();
      if (!isLoggedIn) throw new Error('登录验证失败');
      console.log('✓ 登录验证成功');

      // 6. 返回会话信息
      const sessionInfo = await this.getSessionInfo();
      return sessionInfo;

    } catch (error) {
      console.error('登录失败:', error.message);
      throw error;
    }
  }

  /**
   * 验证登录状态
   */
  async verifyLogin() {
    try {
      // 导航至受保护的页面
      await this.page.goto('https://example.com/profile', {
        waitUntil: 'networkidle',
        timeout: 10000
      });

      // 检查是否重定向到登录页
      const currentUrl = this.page.url();
      const isLoggedIn = !currentUrl.includes('/login');

      return isLoggedIn;
    } catch (error) {
      console.error('验证登录失败:', error.message);
      return false;
    }
  }

  /**
   * 获取会话信息
   */
  async getSessionInfo() {
    // 获取所有cookies
    const cookies = await this.context.cookies();

    // 获取localStorage数据
    const localStorage = await this.page.evaluate(() => {
      return JSON.stringify(window.localStorage);
    });

    // 获取sessionStorage数据
    const sessionStorage = await this.page.evaluate(() => {
      return JSON.stringify(window.sessionStorage);
    });

    return {
      cookies,
      localStorage: JSON.parse(localStorage),
      sessionStorage: JSON.parse(sessionStorage),
      currentUrl: this.page.url(),
      timestamp: new Date().toISOString()
    };
  }

  /**
   * 执行后续业务操作
   */
  async performAction(actionUrl, selector = null) {
    try {
      await this.page.goto(actionUrl, { waitUntil: 'networkidle' });

      if (selector) {
        await this.page.click(selector);
      }

      return await this.page.content();
    } catch (error) {
      console.error('执行操作失败:', error.message);
      return null;
    }
  }

  /**
   * 获取页面截图
   */
  async screenshot(filename = 'screenshot.png') {
    const filepath = path.join(process.cwd(), filename);
    await this.page.screenshot({ path: filepath, fullPage: true });
    console.log(`截图已保存: ${filepath}`);
    return filepath;
  }

  /**
   * 清理资源
   */
  async close() {
    if (this.browser) {
      await this.browser.close();
      console.log('浏览器已关闭');
    }
  }
}

// 导出类
module.exports = HeadlessQRLogin;
```

```python
# qr_login.py
import asyncio
from playwright.async_api import async_playwright
import cv2
import numpy as np
from pyzbar.pyzbar import decode
import json
from datetime import datetime

class HeadlessQRLogin:
    def __init__(self, login_url, poll_interval=1000, max_wait_time=60000):
        self.login_url = login_url
        self.poll_interval = poll_interval / 1000  # 转换为秒
        self.max_wait_time = max_wait_time / 1000
        self.browser = None
        self.context = None
        self.page = None

    async def init(self):
        """初始化Playwright浏览器"""
        self.p = await async_playwright().start()
        self.browser = await self.p.chromium.launch(
            headless=True,
            args=['--no-sandbox', '--disable-dev-shm-usage']
        )

        self.context = await self.browser.new_context(
            ignore_https_errors=True,
            viewport={'width': 1920, 'height': 1080},
            user_agent='Mozilla/5.0 (Windows NT 10.0; Win64; x64)'
        )

        self.page = await self.context.new_page()
        await self.setup_interceptors()

    async def setup_interceptors(self):
        """设置网络拦截"""
        async def on_request(request):
            print(f'>> {request.method} {request.url}')

        async def on_response(response):
            if response.status >= 400:
                print(f'<< {response.status} {response.url}')

        self.page.on('request', on_request)
        self.page.on('response', on_response)

    async def go_to_login_page(self):
        """导航至登录页"""
        try:
            print('正在导航至登录页面...')
            await self.page.goto(self.login_url, wait_until='networkidle')
            print('页面加载完成')
            return True
        except Exception as e:
            print(f'导航失败: {e}')
```

```python
# session_manager.py
import redis
import json
import time
import uuid
from typing import Dict, Optional

class SessionManager:
    def __init__(self, redis_host='localhost', redis_port=6379, db=0):
        self.redis_client = redis.Redis(
            host=redis_host,
            port=redis_port,
            db=db,
            decode_responses=True
        )
        self.session_ttl = 3600  # 1小时
        self.absolute_timeout = 86400  # 24小时绝对超时

    def create_session(self, user_id: str, **metadata) -> str:
        """创建新会话"""
        session_id = str(uuid.uuid4())

        session_data = {
            'userId': user_id,
            'sessionId': session_id,
            'createdAt': int(time.time()),
            'lastActivity': int(time.time()),
            'qrCodeToken': metadata.get('qrCodeToken'),
            'loginMethod': 'qr_code',
            'ipAddress': metadata.get('ipAddress'),
            'userAgent': metadata.get('userAgent'),
            **metadata
        }

        # 保存到Redis，设置过期时间
        key = f'session:{session_id}'
        self.redis_client.setex(
            key,
            self.session_ttl,
            json.dumps(session_data)
        )

        # 创建反向索引（用户ID -> 所有Session）
        user_key = f'user_sessions:{user_id}'
        self.redis_client.sadd(user_key, session_id)
        self.redis_client.expire(user_key, self.absolute_timeout)

        print(f'会话已创建: {session_id}')
        return session_id

    def get_session(self, session_id: str) -> Optional[Dict]:
        """获取会话数据"""
        key = f'session:{session_id}'
        session_data = self.redis_client.get(key)

        if not session_data:
            return None

        session = json.loads(session_data)

        # 更新最后活动时间
        session['lastActivity'] = int(time.time())
        self.redis_client.setex(key, self.session_ttl, json.dumps(session))

        return session

    def destroy_session(self, session_id: str) -> bool:
        """销毁会话"""
        session = self.get_session(session_id)
        if not session:
            return False

        # 从Redis删除会话
        self.redis_client.delete(f'session:{session_id}')

        # 从用户会话集合删除
        user_id = session.get('userId')
        if user_id:
            self.redis_client.srem(f'user_sessions:{user_id}', session_id)

        print(f'会话已销毁: {session_id}')
        return True

    def validate_session(self, session_id: str) -> bool:
        """验证会话有效性"""
        session = self.get_session(session_id)

        if not session:
            return False

        # 检查绝对超时
        created_at = session.get('createdAt', 0)
        if time.time() - created_at > self.absolute_timeout:
            self.destroy_session(session_id)
            return False

        # 检查空闲超时
        last_activity = session.get('lastActivity', 0)
        if time.time() - last_activity > self.session_ttl:
            self.destroy_session(session_id)
            return False

        return True

    def get_user_sessions(self, user_id: str) -> list:
        """获取用户的所有活跃会话"""
        user_key = f'user_sessions:{user_id}'
        session_ids = self.redis_client.smembers(user_key)

        sessions = []
        for session_id in session_ids:
            session = self.get_session(session_id)
            if session:
                sessions.append(session)

        return sessions

    def revoke_all_sessions(self, user_id: str):
        """撤销用户的所有会话"""
        sessions = self.get_user_sessions(user_id)

        for session in sessions:
            self.destroy_session(session.get('sessionId'))

        print(f'用户 {user_id} 的所有会话已撤销')

    def track_activity(self, session_id: str, action: str):
        """记录会话活动"""
        session = self.get_session(session_id)
        if not session:
            return

        # 添加活动日志
        log_key = f'activity_log:{session_id}'
        activity = {
            'action': action,
            'timestamp': int(time.time())
        }
        self.redis_client.rpush(log_key, json.dumps(activity))
        self.redis_client.expire(log_key, self.absolute_timeout)
```

### 3. CSRF防护

```javascript
// csrf-protection.js
const crypto = require('crypto');

class CSRFProtection {
  /**
   * 生成CSRF Token
   */
  static generateToken(sessionId) {
    const randomBytes = crypto.randomBytes(32);
    const timestamp = Date.now().toString();

    // CSRF Token = HMAC(sessionId + timestamp + random)
    const hmac = crypto
      .createHmac('sha256', sessionId)
      .update(timestamp + randomBytes.toString('hex'))
      .digest('hex');

    return {
      token: hmac,
      timestamp: timestamp,
      expiresIn: 3600000 // 1小时
    };
  }

  /**
   * 验证CSRF Token
   */
  static verifyToken(token, sessionId, timestamp) {
    const expected = crypto
      .createHmac('sha256', sessionId)
      .update(timestamp + /* original random bytes */)
      .digest('hex');

    // 使用恒定时间比较防止时序攻击
    return crypto.timingSafeEqual(
      Buffer.from(token),
      Buffer.from(expected)
    );
  }
}

module.exports = CSRFProtection;
```

```javascript
const path = require('path');

class MultiAccountManager {

      return [];
    }
  }

  /**
   * 批量登录
   */
  async loginAll() {
    const results = [];

    for (const [accountId, account] of this.accounts) {
      try {
        console.log(`\n正在登录账号: ${account.name}`);

        const qrLogin = new HeadlessQRLogin({
          loginUrl: account.loginUrl,
          maxWaitTime: 120000
        });

        const sessionInfo = await qrLogin.login();

        // 保存会话信息
        this.sessions.set(accountId, {
          accountId,
          sessionInfo,
          qrLogin,
          loginTime: new Date(),
          status: 'active'

          status: 'success',
          message: '登录成功'
        });

      } catch (error) {
        console.error(`✗ 账号 ${account.name} 登录失败:`, error.message);

        results.push({
          accountId,
          status: 'failed',
          message: error.message
        });
      }
    }

    return results;
  }

  /**
   * 为特定账号执行操作
   */
  async executeForAccount(accountId, action) {
    const session = this.sessions.get(accountId);
    if (!session) {
      throw new Error(`账号 ${accountId} 未登录`);
    }

    if (session.status !== 'active') {
      throw new Error(`账号 ${accountId} 会话已过期`);
    }

    try {
      return await action(session.qrLogin);
    } catch (error) {
      console.error(`账号 ${accountId} 执行操作失败:`, error);
      session.status = 'error';
      throw error;
    }
  }

  /**
   * 并行执行操作
   */
  async executeForAllAccounts(action) {
    const promises = Array.from(this.sessions.entries()).map(
      ([accountId]) => this.executeForAccount(accountId, action)
        .catch(error => ({
          accountId,
          error: error.message
        }))
    );

    return Promise.all(promises);
  }

  /**
   * 定期检查会话有效性
   */
  async validateSessions() {
    const validationResults = [];

    for (const [accountId, session] of this.sessions) {
      try {
        const isValid = await session.qrLogin.verifyLogin();

        if (isValid) {
          console.log(`✓ 账号 ${accountId} 会话有效`);
          validationResults.push({ accountId, valid: true });

          session.status = 'expired';
          validationResults.push({ accountId, valid: false });
        }
      } catch (error) {
        console.error(`验证账号 ${accountId} 失败:`, error);
        validationResults.push({ accountId, valid: false, error });
      }
    }

    return validationResults;
  }

  /**
   * 清理所有会话
   */

    for (const [accountId, session] of this.sessions) {
      try {
        await session.qrLogin.close();

      } catch (error) {
        console.error(`关闭账号 ${accountId} 失败:`, error);
      }
    }

    this.sessions.clear();
  }

  /**
   * 保存会话数据
   */
  async saveSessionData() {
    const sessionData = Array.from(this.sessions.entries()).map(
      ([accountId, session]) => ({
        accountId,

    await fs.writeFile(filepath, JSON.stringify(sessionData, null, 2));

    console.log(`会话数据已保存至 ${filepath}`);
  }
}
```

```javascript
class PerformanceOptimizedQRLogin {
  constructor() {

  async setupResourceInterception(page) {

      // 阻止不必要的资源

          route.abort();
          return;
        }
      }

      route.continue();
    });
  }

  /**
   * 优化2: 页面对象池（复用浏览器context）
   */
  async createPageFromPool(browser) {
    if (this.pagePool.length > 0) {
      console.log('从池中获取页面对象');
      return this.pagePool.pop();
    }

    const context = await browser.createBrowserContext();
    return await context.newPage();
  }

  async returnPageToPool(page) {
    // 清理页面状态
    await page.goto('about:blank');
    this.pagePool.push(page);
  }

  /**
   * 优化3: 并行加载（多个登录任务）
   */
  async parallelLogins(loginConfigs, maxConcurrent = 3) {
    const results = [];
    const queue = [...loginConfigs];
    let running = 0;

    return new Promise((resolve, reject) => {
      const processNext = async () => {
        if (queue.length === 0 && running === 0) {
          resolve(results);
          return;
        }

        if (running >= maxConcurrent || queue.length === 0) {
          return;
        }

        running++;
        const config = queue.shift();

        try {
          const result = await this.performLogin(config);
          results.push(result);
        } catch (error) {
          results.push({ error: error.message });
        } finally {
          running--;
          processNext();
        }
      };

      // 启动并发任务
      for (let i = 0; i < Math.min(maxConcurrent, queue.length); i++) {
        processNext();
      }
    });
  }

  /**
   * 优化4: 智能等待策略
   */
  async waitSmartly(page, condition, maxWait = 30000) {
    const startTime = Date.now();

    while (Date.now() - startTime < maxWait) {
      try {
        const result = await page.evaluate(condition);
        if (result) return true;
      } catch (e) {
        // 页面还未加载，继续等待
      }

      // 动态调整等待时间
      const elapsed = Date.now() - startTime;
      const waitTime = Math.min(1000, 100 * Math.pow(1.1, elapsed / 1000));

      await new Promise(r => setTimeout(r, waitTime));
    }

    return false;
  }

  /**
   * 优化5: 内存管理
   */
  async cleanupResources() {
    // 清空缓存
    this.resourceCache.clear();

    // 关闭未使用的页面
    for (const page of this.pagePool) {
      try {
        await page.close();
      } catch (e) {
        // 忽略错误
      }
    }
    this.pagePool = [];

    // 强制垃圾回收（如果支持）
    if (global.gc) {
      global.gc();
    }
  }
```

```python
import logging

logger = logging.getLogger(__name__)

class RobustQRLogin:
    """带错误恢复机制的QR登录"""

    def __init__(self, max_retries=3):
        self.max_retries = max_retries
        self.retry_delays = [1, 3, 5]  # 指数退避

    async def login_with_retry(self, login_config):
        """带重试的登录"""
        last_error = None

        for attempt in range(self.max_retries):
            try:
                logger.info(f'登录尝试 {attempt + 1}/{self.max_retries}')
                result = await self.perform_login(login_config)
                logger.info('登录成功')
                return result

            except Exception as e:
                last_error = e
                logger.error(f'登录失败: {e}')

                if attempt < self.max_retries - 1:
                    delay = self.retry_delays[min(attempt, len(self.retry_delays) - 1)]
                    logger.info(f'将在 {delay} 秒后重试...')
                    await asyncio.sleep(delay)

        raise Exception(f'登录失败，已重试 {self.max_retries} 次') from last_error

    async def perform_login(self, login_config):
        """执行登录（需实现）"""
        pass

    @staticmethod
    def handle_timeout_error(timeout_seconds=30):
        """装饰器: 处理超时错误"""
        def decorator(func):
            async def wrapper(*args, **kwargs):
                try:
                    return await asyncio.wait_for(
                        func(*args, **kwargs),
                        timeout=timeout_seconds
                    )
                except asyncio.TimeoutError:
                    raise Exception(f'操作超时 ({timeout_seconds}秒)')
            return wrapper
        return decorator

    @staticmethod
    def handle_network_error(func: Callable):
        """装饰器: 处理网络错误"""
        async def wrapper(*args, **kwargs):
            try:
                return await func(*args, **kwargs)
            except Exception as e:
                if 'net' in str(e).lower():
                    raise Exception('网络连接失败，请检查网络配置')
                raise
        return wrapper
```

```python
            await asyncio.sleep(1)

    raise TimeoutError('登录超时')
```

#### Q5: 性能问题与内存泄漏

**原因分析**:
- 页面对象未正确释放
- 事件监听器未清理
- 文件描述符泄漏
- 无限轮询

**解决方案**:

```javascript
// 内存管理最佳实践
class MemoryAwareQRLogin {
  constructor() {
    this.browser = null;
    this.pageLimit = 10;
    this.pages = new Set();
  }

  async createManagedPage(browser) {
    // 监控页面数量
    if (this.pages.size >= this.pageLimit) {
      console.warn('页面池已满，等待释放...');
      await this.waitForPageRelease();
    }

    const page = await browser.newPage();
    this.pages.add(page);

    // 自动清理事件监听
    const cleanup = () => {
      page.removeAllListeners();
      this.pages.delete(page);
    };

    page.on('close', cleanup);
    page.on('error', cleanup);

    return page;
  }

  async waitForPageRelease(timeout = 30000) {
    const start = Date.now();
    while (this.pages.size > this.pageLimit / 2) {
      if (Date.now() - start > timeout) {
        throw new Error('页面释放超时');
      }
      await new Promise(r => setTimeout(r, 100));
    }
  }

  // 受控轮询（有最大迭代次数）
  async controlledPoll(checkFn, maxIterations = 300) {
    for (let i = 0; i < maxIterations; i++) {
      try {
        const result = await checkFn();
        if (result) return true;
      } catch (e) {
        if (i === maxIterations - 1) throw e;
      }

      await new Promise(r => setTimeout(r, 200));
    }
    throw new Error(`轮询 ${maxIterations} 次后仍未成功`);
  }
}
```
